Hold a parameter key and tap <kbd>↑</kbd>/<kbd>↓</kbd> to move that
parameter.

## Performance

| Keys | Action |
|---|---|
| <kbd>A</kbd> + <kbd>↑↓</kbd> | Remix strength (denoise) |
| <kbd>G</kbd> + <kbd>↑↓</kbd> | Structure (hint) strength |
| <kbd>B</kbd> + <kbd>↑↓</kbd> | Prompt blend A↔B |
| <kbd>Z</kbd> + <kbd>↑↓</kbd> | Hero LoRA strength — slot 1 |
| <kbd>X</kbd> + <kbd>↑↓</kbd> | Hero LoRA strength — slot 2 |
| <kbd>F</kbd> | Randomize seed |
| <kbd>Enter</kbd> | Send prompt |
| <kbd>Ctrl/⌘</kbd>+<kbd>Enter</kbd> | Send prompt (inside the textarea) |
| <kbd>Space</kbd> | Pause / resume |

## Engine

| Keys | Action |
|---|---|
| <kbd>E</kbd> + <kbd>↑↓</kbd> | Feedback |
| <kbd>H</kbd> + <kbd>↑↓</kbd> | Shift |
| <kbd>N</kbd> + <kbd>↑↓</kbd> | Noise share |
| <kbd>D</kbd> + <kbd>↑↓</kbd> | ODE control |
| <kbd>0</kbd>–<kbd>7</kbd> + <kbd>↑↓</kbd> | Channel groups G0–G7 |
| <kbd>Shift</kbd>+<kbd>1</kbd>–<kbd>6</kbd> + <kbd>↑↓</kbd> | Keystone channels (CH13, CH14, CH19, CH23, CH29, CH56) |

## DCW corrector

| Keys | Action |
|---|---|
| <kbd>T</kbd> | Toggle DCW on/off |
| <kbd>Shift</kbd>+<kbd>T</kbd> | Cycle DCW mode |
| <kbd>Shift</kbd>+<kbd>W</kbd> | Cycle DCW wavelet |
| <kbd>W</kbd> + <kbd>↑↓</kbd> | DCW low-band push |
| <kbd>Y</kbd> + <kbd>↑↓</kbd> | DCW high-band push |

## Transport, loop & UI

| Keys | Action |
|---|---|
| <kbd>R</kbd> | Record / stop audio |
| <kbd>L</kbd> | Toggle loop (enable region / arm drawing) |
| <kbd>←</kbd> / <kbd>→</kbd> | Nudge loop by one grid step |
| <kbd>Shift</kbd>+<kbd>←</kbd> / <kbd>→</kbd> | Move loop by its own length |
| <kbd>O</kbd> | Toggle Full Controls drawer |
| <kbd>Esc</kbd> | Toggle Full Controls drawer |
| <kbd>Esc</kbd> <kbd>Esc</kbd> | Open expanded (spread) drawer view |
| <kbd>K</kbd> | Toggle kiosk mode |
| <kbd>Shift</kbd>+<kbd>P</kbd> | Performance overlay (dev builds) |
